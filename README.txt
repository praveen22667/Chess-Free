CHESS FREE - installable app (PWA)

1. TRY IT: upload this folder to any HTTPS host (Netlify Drop, GitHub Pages, Cloudflare Pages, Vercel).
2. INSTALL: open the URL on a phone.
   Android Chrome: menu > Install app.   iPhone Safari: Share > Add to Home Screen.
   It then runs full screen and works offline.
3. APP STORES (optional): go to pwabuilder.com, enter your hosted URL and download the
   Android (Google Play) or iOS package. Android also works with Bubblewrap or Capacitor.

Notes: Online play uses the claude.ai runtime, so the Online button is hidden outside claude.ai.
Everything else (computer, same-screen, clocks, review, rating) works offline.
To add online play in a standalone app you need your own backend (e.g. Firebase or Supabase).
